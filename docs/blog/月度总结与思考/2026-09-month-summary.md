## 起于播客

每个月都会听大量的播客，这个月感觉比较喜欢的播客是脉脉 CEO 林凡的访谈，[《86.「明年科技公司就只招 AI 人才了！」和脉脉CEO林凡聊全球 AI 人才动向、组织变革与大模型季报》](https://www.xiaoyuzhoufm.com/episode/6a9daa7ea0210c197dce7a8b)。

我使用 AI 一般只能同时做一两件事情，完全没有办法很好地利用现在 Agent 强大的能力，效率相较于以前有 3 倍的样子，但产出应该没有 2 倍。

而我看到大量的大佬用 AI Agent 做非常多的事情，效率提升可能有 10 倍 / 100 倍，我非常的羡慕。

播客中提到的是：“普通任务 Agent 通常 20-30 分钟即可完成，将目标翻倍至 1 小时，可倒逼用户设计完整的目标与验证闭环。”

作为一个大模型算法工程师，我自然也知道这个原则，但我一直没有去践行。

因此这个月我一直在想，怎么才能 100 倍自己的工作效率呢？

> 我非常期待读者朋友们讲一下你们的方法～

## 终于 Multica

工作毫无疑问是占据我最多时间的内容，但我们这里暂且不聊怎么提升工作效率[^4]。我们聊怎么提升自己工作之外的效率。既然工作占据我们绝大多数时间，那么我们就一定要利用好自己的 Agent，让其在“我们上班的时候，Agent 为我们工作”。这样，“我们作为打工人为老板工作”，“Agent 作为打工人为我们工作”。

所以我们要按照老板一样的思维去安排工作，而不是作为一个工程师。绝大多数时候，我们不应该关心过程，我们关心结果即可。

所以我们需要有一个容器，可以安排任务、验收任务。没错，我们就是需要一个 for Agent 的 Linear。刚好有一个开源软件，叫做 [Multica](https://github.com/multica-ai/multica)，基本符合我的需求。它可以让我早上、晚上的时候给 Agent 布置任务，然后晚上我去验收，上班的时间 Agent 就正常运行。简单理解就是一个看板，很适合一个小任务。

![Multica 任务看板](https://cfcdn.yuanchaofa.com/blog/2026/1791043688027.webp)

## 形成工作流

但是我觉得 Multica 并不够了解我，且自己去写任务也费劲，所以创建任务、管理 Issue 我都是通过我的个人助手——Hermes Agent 处理。通过一个有记忆的个人助手创建任务[^1]、分配任务，而我只需要通过语音输入讲清楚我的诉求，然后 Hermes 可以自动派发和执行，最后晚上我去验收结果以及给出反馈即可。

![Hermes Issue Review 工作流](https://cfcdn.yuanchaofa.com/blog/2026/hermes-issue-review-workflow-gpt-image2.png)

通过这样的方式，我的一些想法落地比以前快了很多，比如更新迭代了 [ThinkTape](https://github.com/ApeCodeAI/thinktape)、LangBuddy、[FinSight](https://github.com/ApeCodeAI/finsight) 等个人的小 GitHub 项目，自我感觉良好（对，有产生了一堆自己用的垃圾，所以我只敢放到 ApeCodeAI 下面： https://github.com/ApeCodeAI 🤣）。

因为这一套模式的启动，我又接了一个[商业化视频广告](https://www.bilibili.com/video/BV1Euaa6uE9V/)，也通过这个模式很好地完成了交付。但这个月由于 B 站修改计税方式，引发了另外一个“关于商业化思考”的事情，就是另外一个故事了[^2]。不过这种苦闷，我不可能埋藏在心里，一定会找一天把这件事情写下来的。

某种程度上可以说，我做视频两年，因为计税方式的改变，我可能不再是为爱发电了，算起来有可能开始倒贴了……等于花了大量的时间扯皮，最后钱没挣到，全给 B 站贡献素材和给国家纳税了（纳税光荣，我举双手赞同合法纳税）。


## 放飞自我

因为上面这个事情的存在，导致我以前关于 B 站商业化的思考毫无意义。当然这是另一个故事[^2]，我们下期再来讲。未来收入也应该可以完全公开了，Maybe build in public 也还可以～

赚不到钱就准备“放飞自我”了～

未来创作应该不会再有数据焦虑了，因为反正也赚不到钱，那为什么不回到最开始做视频的状态[^3]，自己开心最重要呢？

24 年那个国庆假期，我也很怀念啊～
